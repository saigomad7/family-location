도식 2 · y = 2x + 1 의 그래프

그래프를 그리는 방법은 언제나 같습니다 — y절편에 점을 찍고, 기울기만큼 이동해 점을 하나 더 찍고, 두 점을 잇습니다.

2개념MON · 열기

기울기는 “변화의 비율”입니다

기울기 = (y의 증가량) ÷ (x의 증가량)입니다. “오른쪽으로 1 갈 때 위로 얼마나 가는가”라고 읽으면 쉽습니다.

기울기 a그래프 모양생활 속 예
a > 0오른쪽 위로 올라감시간이 갈수록 늘어나는 저금
a < 0오른쪽 아래로 내려감시간이 갈수록 줄어드는 배터리
a가 클수록더 가파름더 빨리 늘거나 줄어듦
b (y절편)y축과 만나는 높이시작할 때 이미 있던 양

생활로 읽어 보기 — 통장에 1만 원이 있고 매주 2만 원씩 저금하면 y = 2x + 1 (단위: 만 원)입니다. b = 1은 시작 금액, a = 2는 매주 늘어나는 속도입니다. 식이 갑자기 이해되는 순간입니다.

중1과 이어지는 부분

중1에서 배운 정비례 y = ax는 b = 0인 경우, 즉 원점을 지나는 일차함수입니다. 일차함수는 그 그래프를 위아래로 b만큼 평행이동한 것입니다. 새로운 것을 배우는 게 아니라 한 칸 올라간 것입니다.

3예제 3개TUE · 채우기

절차대로 따라 풀어 봅니다

예제 1 · 그래프 그리기

y = −3x + 4 의 그래프를 그려 봅시다.

풀이 보기
① y절편에 점을 찍습니다. b = 4 → 점 (0, 4)
② 기울기만큼 이동합니다. a = −3 → 오른쪽 1, 아래로 3 → 점 (1, 1)
③ 두 점을 직선으로 잇습니다. 기울기가 음수면 내려가는 직선입니다.
예제 2 · 두 점에서 식 구하기

두 점 (1, 3), (3, 7)을 지나는 일차함수의 식을 구해 봅시다.

풀이 보기
① 기울기부터. a = 7 − 33 − 1 = 42 = 2
② y = 2x + b 에 한 점을 넣습니다. 3 = 2(1) + b → b = 1
③ 답 · y = 2x + 1
확인: 다른 점 (3,7)도 넣어 봅니다. 2(3) + 1 = 7 ✔
예제 3 · x절편

y = 2x − 6 의 x절편과 y절편을 구해 봅시다.

풀이 보기
① y절편은 x = 0일 때 → y = −6 → 점 (0, −6)
② x절편은 y = 0일 때 → 0 = 2x − 6 → x = 3 → 점 (3, 0)
헷갈리면 이렇게 외웁니다 — x절편은 y를 0으로, y절편은 x를 0으로. 이름과 반대라서 자주 틀립니다.
4오답 노트THU · 오답으로

오늘은 일부러 틀려 보는 날

이 단원에서 자주 걸리는 함정

함정 1

x절편과 y절편을 바꿈

x절편은 y = 0일 때, y절편은 x = 0일 때입니다. 이름과 반대라 가장 많이 틀립니다.

함정 2

기울기를 거꾸로

기울기는 y의 증가량 ÷ x의 증가량입니다. 뒤집어 계산하면 완전히 다른 직선이 됩니다.

함정 3

음수 기울기에서 방향

a = −3이면 오른쪽 1에 아래로 3입니다. 위로 3 가면 반대 방향 직선이 됩니다.

함정 4

y = 3 같은 식

y = 3은 기울기 0인 가로선, x = 3은 세로선입니다. (x = 3은 일차함수가 아닙니다 — 8주차에서 다룹니다.)

5보스전FRI · 설명

문제 5개와 3분 설명

Q1

두 점 (−1, 1), (2, 7)을 지나는 일차함수의 식은?

해설 보기
y = 2x + 3 — 기울기 = (7−1)÷(2−(−1)) = 6÷3 = 2, 점을 넣으면 1 = 2(−1) + b → b = 3
Q2

y = −12x + 4 의 x절편은?

해설 보기
8 — 0 = −½x + 4 → ½x = 4 → x = 8
Q3

기울기가 같고 y절편이 다른 두 직선은 어떤 관계일까요?

해설 보기
서로 평행합니다. 기울어진 정도가 같으니 만나지 않습니다. 5주차에서 “해가 없는 연립방정식”이 바로 이 경우입니다. 8주차에서 이어집니다.
Q4

물통에 물이 200 L 있고 매분 5 L씩 빠져나갑니다. x분 후 물의 양 y를 식으로 쓰고, 40분 후의 양을 구해 봅시다.

해설 보기
y = −5x + 200 · 40분 후 0 L — 처음 양 200이 y절편, 매분 줄어드는 5가 기울기(음수)입니다. −5(40) + 200 = 0
Q5

일차함수 y = ax + b 의 그래프가 오른쪽 아래로 향하고 y축의 음수 부분과 만난다면, a와 b의 부호는?

해설 보기
a < 0, b < 0 — 내려가는 직선이면 기울기가 음수, y축의 아래쪽에서 만나면 y절편이 음수입니다. 그래프 모양만 보고 부호를 읽는 문제는 시험 단골입니다.

아빠에게 3분 설명하기

배운 것y = ax + b 에서 a는 기울기, b는 시작점이라는 것.
예를 들면통장에 1만 원 있고 매주 2만 원씩 넣으면 y = 2x + 1이야. 그래프가 그 저금이야.
내가 틀린 곳x절편이랑 y절편을 바꿔 썼어. x절편은 y를 0으로 놓는 거야.
