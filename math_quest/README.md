# 수학 사다리 12주 (Math Quest)

중2 딸이 중2 수학 전 범위를 하루 20분씩 12주에 걸쳐 **개념 사다리**로 밟아 오르는 학습 프로그램입니다.
`science_quest`·`history_quest`와 같은 구조·같은 문서 언어를 쓰되, 강조색만 남색 계열로 구분했습니다.

## 파일 구성

| 파일 | 누가 보나 | 내용 |

## 세 과목 비교

| | 과학 | 역사 | **수학** |
|---|---|---|---|
| 목요일 | 손으로 (실험) | 사료로 (사료·유물) | **오답으로 (일부러 틀려 보기)** |
| 쌓이는 것 | 노트 12장 | 연표 12칸 | **오답 노트 한 권** |
| 축이 되는 도식 | 개념 도식 | 12주 연표 | **12주 개념 사다리** |

수학만 문제 수가 많은 이유는 **손이 기억해야 하는 과목**이기 때문입니다. 하루로 나누면 3~5문제입니다.

## 12주 커리큘럼 — 사다리 열두 칸

**1구간 · 수와 식** — 1주 유리수와 순환소수 / 2주 지수법칙 / 3주 다항식의 계산 / 4주 일차부등식
**2구간 · 방정식과 함수** — 5주 연립일차방정식 / 6주 연립방정식의 활용 / 7주 일차함수와 그래프 / 8주 일차함수와 일차방정식
**3구간 · 도형과 확률** — 9주 삼각형·사각형의 성질 / 10주 도형의 닮음 / 11주 피타고라스 정리 / 12주 경우의 수와 확률

각 주차 표지에 **"밟고 서는 아래 칸"**(선수 개념)이 적혀 있습니다. 막히면 그 칸의 주차 문서로 내려갑니다.

## 설계 원칙

1. **아래 칸을 먼저 확인한다.** 일차함수에서 막히는 진짜 이유가 중1 좌표평면인 경우가 많습니다.
2. **목요일은 틀리는 날.** 다 맞으면 문제가 쉬웠던 것이니 오히려 아쉬운 날입니다.
3. **오답 노트는 세 줄.** 문제 / 어디서 틀렸는지 / 다음에 쓸 한 줄 규칙. 답을 베껴 쓰지 않습니다.
4. **답이 아니라 이유를 설명한다.** 금요일 3분 설명의 주제는 "왜 그렇게 푸는지"입니다.

## 아빠가 하지 말아야 할 것

먼저 풀어 주기 · "이게 왜 어려워?" · 다른 풀이법 강요 · 속도 재촉.
자세한 내용은 `plan.html`에 있습니다.

## 진행 기록

요일별 체크는 `localStorage`(`math_quest_progress`)에 저장됩니다.
과학·역사와 키가 분리되어 있어 서로 영향을 주지 않습니다.

## 문제집 (`quiz.html`)

12주 과정에 맞춰 **주차마다 10문제**(객관식 7 · 단답형 3), 모두 120문제를 한 문서에 담았습니다.
그 주 공부를 마친 **금요일에 그 주차 10문제만** 푸는 것을 기준으로 만들었습니다.

- 선택지를 누르면 바로 채점되고 해설이 열립니다. 단답형은 답을 쓰고 `확인`을 누릅니다.
- 맨 위 칩으로 주차를 바로 건너뛸 수 있고, 주차마다 점수가 따로 표시됩니다.
- 채점 기록은 `localStorage`(`math_quiz_v1`)에 저장되어 새로고침해도 남습니다. 폰 안에만 저장됩니다.
- 맨 아래 `전체 기록 지우고 처음부터` 버튼으로 초기화합니다.
