2개념MON · 열기

방정식과 같은 것, 다른 것

양변에 하는 일방정식부등식
같은 수를 더하거나 뺀다그대로그대로
양수를 곱하거나 나눈다그대로그대로
음수를 곱하거나 나눈다그대로부등호 방향이 바뀐다
이 한 줄이 이 단원의 전부입니다

음수로 곱하거나 나눌 때만 방향을 바꿉니다. 더하거나 뺄 때는 음수여도 방향을 바꾸지 않습니다. 예를 들어 x + 3 < 5 에서 양변에 −3을 더해도 부등호는 그대로입니다.

푸는 순서는 방정식과 같습니다

3x − 5 ≤ 7① 상수를 오른쪽으로 (양변에 +5)
3x ≤ 12② 문자의 계수로 나눔 (3은 양수 → 방향 그대로)
x ≤ 4③ 답은 범위로 나옵니다

해가 x ≤ 4라는 것은 4, 3, 0, −10 … 4 이하의 모든 수가 답이라는 뜻입니다. 방정식처럼 답이 하나가 아니라 구간입니다. 수직선에 그리면 ●에서 왼쪽으로 뻗은 화살표가 됩니다. (≤는 그 점을 포함하므로 ●, <는 포함하지 않으므로 ○로 그립니다.)

3예제 3개TUE · 채우기

절차대로 따라 풀어 봅니다

예제 1

−2x + 1 > 9 를 풀어 봅시다.

풀이 보기
① 상수를 옮깁니다. −2x > 8
② −2로 나눕니다. 음수이므로 부등호를 뒤집습니다 → x < −4
③ 답 · x < −4 이 문제에서 방향을 안 바꾸면 x > −4가 되어 완전히 반대 답이 됩니다.
예제 2

0.3x − 0.5 < 0.1x + 0.1 을 풀어 봅시다.

풀이 보기
① 소수를 없앱니다. 양변에 10을 곱합니다 (양수라 방향 그대로) → 3x − 5 < x + 1
② 문자는 왼쪽, 숫자는 오른쪽. 3x − x < 1 + 5 → 2x < 6
③ 2로 나눕니다(양수) → x < 3 소수나 분수가 있으면 먼저 정수로 만들고 시작합니다. 실수가 크게 줄어듭니다.
예제 3

한 개에 700원인 사탕을 사고 1000원짜리 봉투 하나를 살 때, 전체 금액이 6000원 이하가 되게 하려면 사탕을 최대 몇 개까지 살 수 있을까요?

풀이 보기
① 개수를 x로 둡니다. 700x + 1000 ≤ 6000
② 상수를 옮깁니다. 700x ≤ 5000
③ 나눕니다. x ≤ 7.14…
④ 개수는 자연수이므로 최대 7개입니다. 활용 문제에서는 마지막에 “개수는 정수” 같은 조건을 꼭 확인합니다.
4오답 노트THU · 오답으로

오늘은 일부러 틀려 보는 날

이 단원에서 자주 걸리는 함정

함정 1

방향을 안 바꿈

−3x < 9의 답은 x < −3이 아니라 x > −3입니다. 음수로 나눴으니 뒤집습니다.

함정 2

더할 때도 바꿈

반대 실수입니다. x − 5 > 2에서 +5를 해도 방향은 그대로입니다. 뒤집는 것은 곱셈·나눗셈뿐입니다.

함정 3

이항할 때 부호

3x − 5 ≤ 7에서 −5를 넘기면 +5가 됩니다. 방정식과 똑같습니다.

함정 4

활용에서 단위·정수

“최대 몇 개”는 소수점이 나와도 정수로 내림합니다. 7.14개면 7개입니다.

연습 5문제

연습 1

x + 4 < 9

답 보기
x < 5 — 더하기·빼기는 방향 그대로입니다.
연습 2

−x ≥ 3

답 보기
x ≤ −3 — 양변에 −1을 곱했으므로 뒤집습니다.
연습 3

2x + 1 > x + 6

답 보기
x > 5 — 문자를 왼쪽으로 모으면 x > 5입니다.
연습 4

−4x + 2 ≤ 10

답 보기
x ≥ −2 — −4x ≤ 8 에서 −4로 나누며 뒤집습니다.
연습 5

x/2 − 1 < 2

답 보기
x < 6 — 양변에 2를 곱하면(양수) x − 2 < 4 → x < 6

문제 5개와 1구간 전체 설명

Q1

5 − 2x ≥ 11 을 풀어 봅시다.

해설 보기
x ≤ −3 — −2x ≥ 6 에서 −2로 나누며 뒤집습니다.
Q2

3(x − 2) < x + 4

해설 보기
x < 5 — 괄호를 풀면 3x − 6 < x + 4 → 2x < 10 (3주차 분배가 여기서 쓰입니다)
Q3

부등식 2x − 1 < 7 을 만족하는 자연수 x를 모두 구해 봅시다.

해설 보기
1, 2, 3 — x < 4 이고 자연수이므로 1, 2, 3입니다. 4는 포함되지 않습니다.
Q4

한 권에 1200원인 공책을 사려고 합니다. 10000원으로 최대 몇 권을 살 수 있을까요?

해설 보기
8권 — 1200x ≤ 10000 → x ≤ 8.33… 이므로 최대 8권입니다.
Q5

1구간 통합 — 1~4주차를 한 문장씩으로 이어 봅시다.

해설 보기
① 분수를 소수로 바꾸면 분모에 2와 5만 있을 때 딱 떨어집니다.
② 지수는 몇 번 곱했는지 세는 것이라, 곱하면 더하고 괄호면 곱합니다.
③ 다항식은 문자와 지수가 같은 것끼리만 더하고, 괄호 앞 −는 안의 부호를 모두 바꿉니다.
④ 부등식은 방정식과 같은데 음수로 곱하거나 나눌 때만 방향이 바뀝니다.
이 네 줄이 1구간 전체입니다.

아빠에게 3분 설명하기

배운 것부등식은 방정식이랑 푸는 법이 같은데, 음수로 나눌 때만 방향이 바뀐다는 것.
왜2 < 5 인데 −1을 곱하면 −2 > −5가 되잖아. 수직선에서 순서가 뒤집혀서 그래.
1구간 전체순환소수 → 지수법칙 → 다항식 → 부등식. 사다리 네 칸을 짚으며 설명합니다.
