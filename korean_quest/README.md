중학교 국어에서 **그림이 있어야 이해되는 부분**만 골라 단원별로 정리한 문서 모음입니다.
과학의 `heart.html`·`photo.html`과 같은 형식이며, **딸의 폰에서 보는 것을 전제로** 만들었습니다.

## 연역과 귀납 (`logic.html`)

중학교 국어 성취기준 **“글에 사용된 다양한 논증 방법을 파악하며 읽는다”**에 해당하는 부분입니다.
연역·귀납·유추 세 가지를 다룹니다.

구성: 논증이란(주장+근거) → 연역(삼단 논법) → 귀납(사례 모으기) →
**화살표 방향 한 장** → 확실성과 새로움의 맞바꿈 → 각자 무너지는 자리(전제 거짓 / 성급한 일반화) →
유추 → **판별 순서도와 연습 4문제** → 함정 5개 → 빈칸 채우기 + 확인 문제 6개.

설계 원칙은 과학 문서와 같습니다 — **외울 항목을 결과로 바꾸기.**
두 방법의 차이를 정의로 외우지 않고 **화살표의 방향 하나**로 가르게 했고,
각 방법의 약점도 "어디를 의심해야 하는가"로 바꿔 두었습니다.

예제는 전부 **중학생의 생활에서 가져왔습니다** — 아이돌 콘서트 예매, 반별 수학 평균,
드라마 시청, 학원 소문, 토끼와 햄스터.

주소: `https://saigomad7.github.io/family-location/korean_quest/logic.html`
