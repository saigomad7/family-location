# 과학 등반 12주 (Science Quest)

중2 딸이 중1부터 누적된 과학 개념을 하루 20분씩 12주에 걸쳐 따라잡는 학습 프로그램입니다.
**딸의 폰에서 보는 것을 전제로** 만들었습니다.

## 파일 구성

| 파일 | 누가 보나 | 내용 |
|---|---|---|
| `index.html` | **딸** | 12주 허브. 주차별 문서 목록, 완료 표시, 전체 진행률 |
| `week01.html` ~ `week03.html` | **딸** | 한 문서 = 일주일치 학습 자료 (현재 3주차까지 공개) |
| `plan.html` | 아빠 | 추진 계획 — 설계 근거, 아빠 역할 설명서, 변수 대응 |

## 딸에게 줄 주소

```
https://saigomad7.github.io/family-location/science_quest/
```

이 주소 하나만 보내면 됩니다. 폰 홈 화면에 추가해 두면 앱처럼 열립니다.

## 주차별 문서의 구조

모든 주차가 같은 순서로 되어 있어서, 한 번 익히면 12주 내내 똑같이 굴러갑니다.

| 순서 | 내용 | 시간 |
|---|---|---|
| 이번 주 지도 | 그 주 개념을 그림(SVG) 한 장으로 | — |
| 월 · 열기 | 개념 읽고 **궁금한 질문 3개 적기** | 20분 |
| 화 · 채우기 | 노트 한 장 정리 (양식 제공) | 20분 |
| 목 · 손으로 | 집에 있는 물건으로 하는 실험 + 안전 수칙 | 20~30분 |
| 금 · 보스전 | 문제 5개(탭하면 해설) + **아빠에게 3분 설명** | 20분 |

## 12주 커리큘럼

**캠프 1 · 물질** — 1주 입자의 눈 ✅ / 2주 원소와 불꽃 ✅ / 3주 원자와 분자 ✅ / 4주 이온과 앙금
**캠프 2 · 전기와 성질** — 5주 정전기와 전하 / 6주 전류·전압·저항 / 7주 전류의 자기 작용 / 8주 물질의 특성
**캠프 3 · 생명과 지구** — 9주 광합성과 호흡 / 10주 에너지 배달 경로 / 11주 지구와 달의 운동 / 12주 열의 이동 + 최종 강의

각 주차는 **중1 연결고리 하나를 먼저 복구한 뒤** 그 주의 중2 개념으로 올라갑니다.

**현재 1~3주차까지 만들어져 있습니다.** 세 주를 실제로 돌려 보고 리듬(분량·실험 난이도·막히는 지점)을 확인한 뒤
4주차부터 이어서 만드는 것이 낫다고 판단했습니다. 허브에서 4주차 이후는 '준비 중'으로 표시됩니다.

## 문서 톤

`CUI Agent 내부 구조 분석` 문서와 같은 시각 언어를 씁니다 —
세이지 배경(`#DCE2DB`), 딥그린 강조(`#1F6249`), IBM Plex Sans KR + Mono,
번호가 붙은 섹션(`step-no`), 흰 도식 박스(`fig`), 어두운 머리글의 표, 앰버/베리 콜아웃.
다만 화면 폭은 **폰 세로 화면 기준**으로 다시 잡았습니다.

## 진행 기록

요일별 체크는 브라우저 `localStorage`(`science_quest_progress`)에 저장되며,
허브(`index.html`)와 추진 계획(`plan.html`)이 같은 값을 공유합니다.
**딸의 폰 안에만 저장**되고 서버로 전송되지 않습니다.

## 학교 진도와 다를 때

교과서 출판사와 학교 진도에 따라 단원 순서가 다릅니다.
그럴 때는 그 주 문서의 **개념 부분만 학교 진도로 바꿔 끼우고**, 요일 리듬과 보스전 구조는 그대로 씁니다.

## 문서 수정

주차 문서는 공통 셸(스타일·스크립트)과 본문 조각을 합쳐 만들었습니다.
완성된 HTML만 저장소에 있으므로 수정할 때는 해당 `weekNN.html`을 직접 고치면 됩니다.
각 파일은 스타일·스크립트를 포함한 **단일 파일**이라 하나만 따로 보내도 그대로 열립니다.
스타일을 바꿀 때는 모든 주차 파일의 `<style>` 블록이 동일하다는 점에 유의하세요.
