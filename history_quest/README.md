# 역사 항해 12주 (History Quest)

중2 딸이 한국사 전체 흐름을 하루 20분씩 12주에 걸쳐 <b>연표 한 장</b>으로 잇는 학습 프로그램입니다.
`science_quest`와 같은 구조·같은 문서 언어를 쓰되, 강조색만 자주 계열로 구분했습니다.

## 파일 구성

| 파일 | 누가 보나 | 내용 |
|---|---|---|
| `index.html` | **딸** | 12주 허브. 구간별 목록, 주차별 완료 표시, 전체 진행률 |
| `week01.html` ~ `week12.html` | **딸** | 한 문서 = 일주일치 학습 자료 |
| `quiz.html` | **딸** | 역사 문제집 120제 — 12주 × 10문제(객관식 7 · 단답형 3), 누르면 즉시 채점 |
| `plan.html` | 아빠 | 추진 계획 — 설계 근거, 아빠 역할, 확인 방법, 변수 대응 |

## 과학 프로그램과 다른 점

같은 요일 리듬(월 열기 · 화 채우기 · 목 · 금 보스전)을 쓰지만 세 가지가 다릅니다.

| | 과학 | 역사 |
|---|---|---|
| 목요일 | **손으로** — 집에서 하는 실험 | **사료로** — 사료·유물·지도·인터뷰 |
| 쌓이는 것 | 노트 12장 | **연표 12칸** (벽에 붙여 매주 한 칸씩) |
| 화요일 정리 | 개념 노트 한 장 | 연표 한 칸 + **원인 → 사건 → 결과** 표 + 인물 카드 2장 |

## 12주 커리큘럼 — 연표 열두 칸

**1구간 · 고대** — 1주 선사와 고조선 / 2주 삼국의 성장 / 3주 통일신라와 발해 / 4주 고려의 성립
**2구간 · 고려와 조선** — 5주 고려 후기 / 6주 조선의 건국 / 7주 사림과 두 전쟁 / 8주 조선 후기
**3구간 · 근현대** — 9주 개항과 근대화 / 10주 일제 강점기 / 11주 광복과 전쟁 / 12주 산업화와 민주화

시간 길이가 아니라 **배우는 분량**으로 나눴습니다. 근현대가 시험에 더 많이 나오기 때문에 뒤쪽 한 칸이 짧습니다.

## 설계 원칙

1. **한 주에 시대 하나, 사건 세 개만.** 더 넣지 않는 것이 핵심입니다.
2. **모든 사건을 원인 → 사건 → 결과로.** 이유 없이 외운 것은 시험이 끝나면 사라집니다.
3. **연도는 순서를 잡는 도구.** 연도 암기 시험은 보지 않습니다.
4. **평가가 갈리는 대목은 결론을 주지 않습니다.** 사료를 보여 주고 "너는 어떻게 생각해?"로 묻습니다.

## 가족 인터뷰

10주차(일제 강점기)와 11·12주차(광복·전쟁·현대)에는 **할머니·할아버지, 부모님 인터뷰**가 들어 있습니다.
교과서의 연도가 우리 집 이야기가 되는 활동이고, 12주차에서 **3대 연표**로 완성됩니다.
미리 통화 약속을 잡아 두시면 좋습니다.

## 진행 기록

요일별 체크는 브라우저 `localStorage`(`history_quest_progress`)에 저장됩니다.
과학 프로그램(`science_quest_progress`)과 키가 분리되어 있어 서로 영향을 주지 않습니다.

## 교과서와 다를 때

학교에서 세계사(역사①)를 먼저 배우는 경우가 많습니다. 그래도 이 순서를 바꾸지 않는 편이 낫습니다.
한국사 흐름이 자리를 잡으면 세계사는 그 위에 얹으면 되기 때문입니다.
시험 범위가 세계사라면 그 주의 '사료로'와 '보스전'만 시험 범위로 바꿔 쓰면 됩니다.

## 문제집 (`quiz.html`)

12주 과정에 맞춰 **주차마다 10문제**(객관식 7 · 단답형 3), 모두 120문제를 한 문서에 담았습니다.
그 주 공부를 마친 **금요일에 그 주차 10문제만** 푸는 것을 기준으로 만들었습니다.

- 선택지를 누르면 바로 채점되고 해설이 열립니다. 단답형은 답을 쓰고 `확인`을 누릅니다.
- 맨 위 칩으로 주차를 바로 건너뛸 수 있고, 주차마다 점수가 따로 표시됩니다.
- 채점 기록은 `localStorage`(`history_quiz_v1`)에 저장되어 새로고침해도 남습니다. 폰 안에만 저장됩니다.
- 맨 아래 `전체 기록 지우고 처음부터` 버튼으로 초기화합니다.
