# 우리 가족 공부 (Family Study)

가족이 각자 공부한 시간을 기록하고 서로 확인·응원하는 모바일 웹앱입니다.
[우리 가족 위치](../) 앱과 **같은 Firebase 프로젝트 / 같은 가족 코드**를 쓰기 때문에,
위치 앱에서 이미 등록한 가족 이름이 그대로 나옵니다.

- 프론트엔드: HTML 단일 파일 → **GitHub Pages** 배포
- 데이터 동기화: **Firebase Realtime Database** (위치 앱과 동일 프로젝트)

## 주요 기능

| 기능 | 설명 |
|---|---|
| 공부 타이머 | 과목(국어·영어·수학·과학·사회·독서·기타)을 고르고 시작 → 20초마다 자동 저장. 앱을 닫았다 열어도 이어집니다 |
| 직접 입력 | 타이머를 못 켰을 땐 "공부한 시간 직접 추가"로 분 단위 입력 |
| 하루 목표 | ⚙️에서 하루 목표(분)를 정하면 진행 막대와 그래프 목표선에 표시 |
| 가족 현황 | 오늘 가족 각자의 공부 시간·목표 달성률을 실시간으로 확인. 공부 중이면 "○○ 중" 표시 |
| 응원 👏 | 가족에게 응원을 보내면 상대 화면에 알림이 뜹니다 (하루 단위) |
| 최근 7일 그래프 | 사람별 일일 공부량 막대그래프 + 표 보기, 과목별 누적 시간 |

## 배포 / 사용

이 폴더는 `family-location` 저장소 안에 있으므로 별도 설정 없이 함께 배포됩니다.

- 주소: `https://saigomad7.github.io/family-location/family_study/`
- 처음 열면 **가족 코드**를 입력합니다. 위치 앱과 **같은 코드**를 쓰세요.
- 가족 목록에서 본인 이름을 선택하면 끝입니다.
  (목록에 없는 새 가족을 추가하려면 위치 앱과 동일한 **관리자 코드**가 필요합니다.)
- 🔗 버튼으로 `?f=가족코드`가 들어간 초대 링크를 보낼 수 있고,
  이 링크로 들어오면 코드 입력 없이 이름만 고르면 됩니다.
- 홈 화면에 추가(PWA): iPhone Safari 공유 → "홈 화면에 추가",
  Android Chrome 메뉴 → "홈 화면에 추가"

## 데이터 구조 (Realtime Database)

```
families/{가족코드}/
  members/{멤버id}          # 위치 앱과 공유 (이름, 색)
  adminPin                  # 위치 앱과 공유 (SHA-256)
  study/{YYYY-MM-DD}/{멤버id}   # { total: 초, subjects: { 과목: 초 }, updated }
  studyGoals/{멤버id}       # 하루 목표 (분)
  studyLive/{멤버id}        # { subject, ts } — 90초 안에 갱신되면 "공부 중"
  cheers/{YYYY-MM-DD}/{받는id}/{보낸id}   # 응원 타임스탬프
```

위치 앱과 노드 이름이 겹치지 않으므로 기존 데이터와 충돌하지 않습니다.
Realtime Database 규칙도 위치 앱에서 쓰던 것(`families/$family` 아래만 읽기·쓰기 허용)을
그대로 사용하면 됩니다.

## 참고

- 타이머는 화면이 켜져 있는 동안 wake lock으로 화면 꺼짐을 막습니다.
  브라우저를 완전히 닫으면 그 시점까지 저장된 시간만 남습니다.
- 자정이 지나면 자동으로 다음 날 기록으로 이어서 쌓입니다.
- 그래프는 최근 14일치만 내려받아 그리므로 데이터가 쌓여도 느려지지 않습니다.
